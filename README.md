# Menu Restaurante

    Este projeto que simula  um menu de restaurante que permite aos usuários visualizar e adicionar itens ao carrinho de compras.

## Pré-requisitos

- Node.js (versão 14 ou superior)
- NPM ou Yarn


## Instalação

1. Clone o repositório
2. Instale as dependências (yarn install)
3. Rode o projeto (yarn dev)
4. Rode os testes (yarn test)

## Testes

Os testes são feitos com Jest e React Testing Library.
